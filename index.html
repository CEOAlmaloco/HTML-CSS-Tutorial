Fundamentos de HTML

HTML (HyperText Markup Language) es el lenguaje estándar para crear páginas web. Define la estructura y el contenido de una página.

Elementos básicos: Todo documento HTML contiene elementos como <html>, <head> y <body>.

Estructura básica de un documento HTML

<!DOCTYPE html> <!-- Define el tipo de documento -->
<html lang="es"> <!-- Elemento raíz con atributo de idioma -->
<head> <!-- Contiene metadatos y enlaces a recursos externos -->
    <meta charset="UTF-8"> <!-- Codificación de caracteres -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Título de la página</title> <!-- Título en la pestaña del navegador -->
</head>
<body> <!-- Contiene el contenido visible de la página -->
    <h1>Mi primera página</h1>
    <p>Este es un párrafo de ejemplo.</p>
</body>
</html>

HTML Semántico

El HTML semántico utiliza etiquetas que describen el significado del contenido, mejorando la accesibilidad y el SEO.

Etiquetas semánticas principales

<header>   <!-- Cabecera de la página o sección -->
<nav>      <!-- Contiene enlaces de navegación -->
<main>     <!-- Contenido principal de la página -->
<section>  <!-- Sección temática del contenido -->
<article>  <!-- Contenido independiente y autocontenido -->
<aside>    <!-- Contenido relacionado indirectamente (sidebar) -->
<footer>   <!-- Pie de página o sección -->
<figure>   <!-- Contenido independiente como imágenes, diagramas -->
<figcaption> <!-- Leyenda para figure -->
<header> Cabecera
<nav> Navegación
<article> Artículo principal
<aside> Contenido relacionado
<footer> Pie de página

Ventajas del HTML semántico: Mejor SEO, mayor accesibilidad, código más legible y mantenible.

Fundamentos de CSS

CSS (Cascading Style Sheets) se usa para dar estilo y diseño a páginas web.

Sintaxis básica de CSS

selector {
    propiedad: valor;
    otra-propiedad: valor;
}

Tipos de selectores

Selector Ejemplo Descripción
Selector de elemento p { ... } Selecciona todos los elementos <p>
Selector de clase .clase { ... } Selecciona elementos con class="clase"
Selector de ID #id { ... } Selecciona el elemento con id="id"
Selector de atributo [type="text"] { ... } Selecciona elementos con atributo específico
Selector descendente div p { ... } Selecciona todos los <p> dentro de <div>
Selector de hijo directo div > p { ... } Selecciona <p> que son hijos directos de <div>

Posicionamiento

Static (por defecto)

Posicionamiento normal en el flujo del documento.

Relative

Posicionado relativo a su posición normal.

Absolute

Posicionado relativo al ancestro posicionado más cercano.

Fixed

Posicionado relativo al viewport (no se mueve al hacer scroll).

Sticky

Híbrido entre relative y fixed (se pega al hacer scroll).

Efectos y Animaciones CSS

Transiciones

Permiten cambiar valores de propiedades de forma suave durante un periodo de tiempo.

button {
    transition: all 0.3s ease;
    /* Propiedades que cambian al pasar el cursor */
}
button:hover {
    background-color: #e74c3c;
    transform: scale(1.1);
}

Transformaciones

rotate(15deg)
scale(1.2)
skewX(20deg)
translate(10px, 20px)

Animaciones

@keyframes pulse {
    0% { transform: scale(1); }
    50% { transform: scale(1.1); }
    100% { transform: scale(1); }
}

.elemento {
    animation: pulse 2s infinite;
}

Diseño Responsive

Crea sitios que se adapten a diferentes tamaños de pantalla usando media queries.

Media Queries

/* Estilos para móviles (default) */

/* Tablets */
@media (min-width: 768px) {
    /* Estilos específicos para tablets */
}

/* Escritorios */
@media (min-width: 992px) {
    /* Estilos específicos para escritorios */
}

/* Pantallas grandes */
@media (min-width: 1200px) {
    /* Estilos para pantallas grandes */
}

Enfoques Responsive

Mobile First

Diseña primero para móviles y luego agrega estilos para pantallas más grandes.

Unidades relativas

Usa %, vw, vh, rem, em en lugar de px fijos.

Imágenes flexibles

Usa max-width: 100% para que las imágenes no excedan su contenedor.

Prueba siempre: Usa las herramientas de desarrollador de tu navegador para probar diferentes tamaños de pantalla.
